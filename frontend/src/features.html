PICNYM features

Anonymous messages that go beyond text.

One shareable link can receive text, photos, voice notes and polls. Inbox owners can reply, share branded cards, block abusive senders and manage everything from one place.

Create your inboxRead safety rules

Anonymous text

Receive messages without showing the sender's profile to the inbox owner.

Photo messages

Send supported images with an optional caption, giving anonymous conversations more context.

Voice notes

Record a voice note in supported browsers or choose an audio file, then send it through the same anonymous link.

Anonymous polls

Create polls with shareable links and let people vote without exposing their identity to the poll creator.

Shareable image cards

Turn messages and replies into branded image cards that are easy to post on social platforms.

Private inbox controls

Reply, delete messages, block abusive senders, select multiple messages and keep the inbox automatically refreshed.

Account access

PICNYM accounts make inbox ownership portable across devices instead of depending only on one browser.

Installable web app

PICNYM can be installed as a web app on supported phones while keeping the same web account and inbox.
